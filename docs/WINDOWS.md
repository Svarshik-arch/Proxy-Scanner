# Запуск на Windows

Готовые файлы — в папке [`release`](../release): `proxy-scanner.exe`, `masscan64.exe`
и скрипт запуска `proxy-scanner.cmd` + `proxy-scanner.ps1`. Положите их в одну папку.

Требования: Windows 10/11 x64. Программа работает без установки и без интернета.

## Быстрый запуск (скрипт)

Дважды щёлкните `proxy-scanner.cmd` (или запустите его из командной строки).

Скрипт сам выполняет все подготовительные шаги:

1. запрашивает права администратора (окно UAC) — они нужны режиму masscan;
2. снимает с файлов «метку интернета», из-за которой Windows SmartScreen блокирует
   скачанные программы или показывает предупреждение;
3. проверяет, установлен ли Npcap; если нет и рядом лежит установщик `npcap-*.exe`,
   запускает его (в закрытом контуре положите установщик заранее);
4. запускает `proxy-scanner.exe`.

`proxy-scanner.cmd` запускает `proxy-scanner.ps1` в обход политики выполнения
скриптов PowerShell, поэтому ничего настраивать не нужно.

Режимы скрипта:

| Команда | Что делает |
|---|---|
| `proxy-scanner.cmd` | запуск с правами администратора (по умолчанию) |
| `proxy-scanner.cmd -User` | без прав администратора: доступен только режим TCP-connect |
| `proxy-scanner.cmd -NoInstall` | не запускать установщик Npcap |
| `proxy-scanner.cmd -CheckOnly` | только проверить окружение и вывести результат, программу не запускать |
| `proxy-scanner.cmd --renderer glow` | любые другие аргументы передаются программе (здесь — OpenGL вместо DirectX 12) |

## Ручной запуск

### Права администратора

masscan отправляет пакеты через драйвер Npcap, для этого нужны права администратора.
Режиму TCP-connect они не нужны.

- Щёлкните `proxy-scanner.exe` правой кнопкой → «Запуск от имени администратора», или
- запустите программу как обычно и нажмите в шапке «Перезапустить от имени администратора».

### Npcap

Нужен только для режима masscan. Установщик: <https://npcap.com/#download>
(скачайте заранее, если на рабочей станции нет интернета). При установке
оставьте настройки по умолчанию; режим совместимости с WinPcap не нужен.

Проверить установку: в шапке программы индикатор «Npcap» должен быть зелёным.

### Предупреждение SmartScreen

Если при запуске появилось «Система Windows защитила ваш компьютер»:
«Подробнее» → «Выполнить в любом случае». Либо снимите метку вручную:
свойства файла → флажок «Разблокировать» → «ОК», или в PowerShell:

```powershell
Unblock-File .\proxy-scanner.exe, .\masscan64.exe
```

## Если окно не открывается

- На виртуальных машинах и по RDP без видеоускорения: `proxy-scanner.cmd --renderer glow`.
- Сообщение об ошибке графики показывается в отдельном окне — пришлите его текст.

Параметры для максимальной скорости сканирования — в [TUNING.md](TUNING.md).
